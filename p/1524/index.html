Java代码运行原理

Java运行原理

  • 先编译

    • 把我们书写的代码编译成计算机能识别的内容–字节码文件

    • 我们能认识英文、字符等，计算机只认识二进制的内容

  • 再解释执行

    • java的虚拟机可以解释执行源文件编译产生的字节码文件

Java跨平台运行原理

  • 跨平台==跨系统

  • 因为java的代码最终是运行在java虚拟机中的

  • 只要当前的这台机器安装了虚拟机，就能运行java程序，和操作系统无关

  • 不管是什么操作系统，只要安装了java虚拟机就能运行java程序

名词解释（自行补全）

JDK 用于开发 Java 应用程序。它包含编译器（javac）可将 .java 源代码编译为 .class 字节码，也包含运行程序所需的 JRE。

JRE 提供运行 Java 应用程序所需的最小环境。如果你只需要运行别人开发好的 Java 程序（比如启动一个 .jar 文件），安装 JRE 就够了。

JVM 是运行 Java 字节码（.class 文件）的运行时环境。它负责将编译后的 Java 字节码解释或编译成当前操作系统的机器指令并执行。
