面向对象入门【掌握】

面向对象概述

  • 面向过程 分析出解决问题所需要的步骤，然后用函数把这些步骤一步一步实现，使用的时候一个一个依次调用
  • 面向对象 是指在计算机程序中，模拟现实世界中的概念，借助对象的描述在计算机程序中用类似的实体模拟现实世界中的实体
  • OO 面向对象(Object Oriented)是软件开发方法，一种编程范式。
  • OOP 面向对象程序设计(Object Oriented Programming)作为一种新方法，其本质是以建立模型体现出来的抽象思维过程和面向对象的方法。
  • 对象

类

  • 类是一组具有相同(相似)属性和行为事物的统称
    • 五菱之光、凯迪拉克、比亚迪都称为汽车
    • 联想电脑、戴尔电脑、华硕电脑都成为电脑

对象

  • 对象是具体存在的事物
    • 张三的联想电脑
    • 李四的大黄狗

类和对象的关系

  • 类是对象的模板，是对对象的抽象描述
  • 对象是类的实例，是类的具体体现

对象的属性

概述

  • 使用类创建出来的对象称为类的实例
  • 这样的对象中的属性称为对象的实例变量/成员变量
  • 定义的位置在类中方法外
  • 一个类可以创建很多个对象，每个对象都拥有自己的属性

实例变量和局部变量

  • 实例变量
    • 定义在类中方法外
    • 是类的成员之一
  • 局部变量
    • 定义在方法中
      • 方法的声明部分
      • 方法的实现部分
选项 实例变量 局部变量
定义位置 类中方法外 方法中
作用范围 整个类都能使用 方法中可以使用
默认值 有，和数据类型相关 无，使用之前必须赋值
优先级 重名时候局部变量优先
存储位置 堆内存 栈内存

对象的方法

概述

  • 对象有属性
    • 实例变量
  • 对象有方法
    • 实例方法
  • 实例方法定义在类中方法外
  • 实例方法需要使用对象调用

实例方法的特点

  • 实例方法不再使用static修饰
  • 实例方法需要使用对象调用

方法重载【重点】【掌握】

概述

  • 在同一个类中，出现了多个名字相同的方法，但是他们的参数列表不同

特征

  • 在同一个类中
  • 方法名字相同
  • 参数列表不同
    • 参数数量不同
    • 参数类型不同
    • 参数顺序不同
  • 和修饰符、返回值类型无关

/**
 *	动物类
 */
public class Animal {
	// 属性
	String breed;
	int age;
	double weight;
	String color;
	String sex;
	double length;
	
	public Animal() {
		System.out.println("我是没有参数的构造方法...");
		System.out.println(this.hashCode());
	}

	public Animal(String breed, int age, double weight, String color, String sex, double length) {
		super();
		this.breed = breed;
		this.age = age;
		this.weight = weight;
		this.color = color;
		this.sex = sex;
		this.length = length;
	}

	// 方法
	public void show() {
		System.out.println("Animal [breed=" + breed + ", age=" + age + ", weight=" + weight + ", color=" + color + ", sex=" + sex
				+ ", length=" + length + "]");
	}

	// 展示对象的信息,加上这个方法输出对象名的时候打印的不再是地址
	@Override
	public String toString() {
		return "Animal [breed=" + breed + ", age=" + age + ", weight=" + weight + ", color=" + color + ", sex=" + sex
				+ ", length=" + length + "]";
	}
	
}

public class Demo01 {
	public static void main(String[] args) {
		// 使用无参数的构造方法创建对象,对象创建完成之后是没有属性数据的
		Animal animal = new Animal();
		System.out.println("animal ==>" + animal.hashCode());
		System.out.println(animal);
		animal.breed = "大象";
		animal.age = 22;
		animal.color = "灰色";
		animal.length = 3000;
		animal.sex = "雄性";
		animal.weight = 2000;
		System.out.println(animal);
		
		// 使用有参数的构造得到创建对象,对象创建完成之后是有属性数据的
		Animal animal2 = new Animal("长颈鹿", 18, 1000, "黄色", "雌性", 4000);
		System.out.println("animal2 ==>" + animal2.hashCode());
		System.out.println(animal2);
	}
}

/**
 * 	猫类
 *	属性
 *		种类
 *		年龄
 *		重量
 *		颜色
 *		性别
 *		长度
 *	方法
 *		展示
 *		
 */
public class Cat {
	// 属性
	String breed;
	int age;
	double weight;
	String color;
	String sex;
	double length;
	
	/**
	 * 	如果用户没有显式定义任何构造方法--》显式定义--手写出来
	 * 	JVM自动生成一个空参的构造方法
	 */
	public Cat() {
		System.out.println(this);
	}
	
	/**
	 *	自定义有参数的构造方法
	 * @param breed
	 */
	public Cat(String breed, int age, double weight, String color, String sex, double length) {
		this.breed = breed;
		this.age = age;
		this.weight = weight;
		this.color = color;
		this.sex = sex;
		this.length = length;
	}

	// 方法
	public void show() {
		System.out.println("Cat [breed=" + breed + ", age=" + age + ", weight=" + weight + ", color=" + color + ", sex=" + sex
				+ ", length=" + length + "]");
	}
}

public class TestCat {
	public static void main(String[] args) {
		/**
		 * 	创建Cat类型的对象
		 */
		// 创建对象
		Cat cat01 = new Cat();
		System.out.println("cat01 == " + cat01);
		
		// 调用方法展示信息--所有的属性都是默认值
		cat01.show();
		
		// 给属性赋值
		cat01.breed = "美短";
		cat01.color = "黄色";
		cat01.age = 2;
		cat01.sex = "雄性";
		cat01.length = 300;
		cat01.weight = 2500;
		
		cat01.show();
		
		System.out.println("------------------------------------");
		
		// 调用Cat类中的有参构造方法,创建cat02对象,创建的过程中给cat02的属性赋值
		Cat cat02 = new Cat("狸花猫", 3, 3000, "黑灰色", "雄性", 350);
		// 调用方法展示信息
		cat02.show();
	}
}

构造器的特点

  • 构造器的名字和类名必须完全一致
  • 构造器没有返回值和返回值类型
  • 如果自己没有显示定义任何构造器,JVM赠送一个空参构造器
  • 如果自己显示定义了任何一个构造器，Jvm不再赠送空参构造器

public class Student {
	// 属性
	String name;
	int age;
	double weight;
	String gender;
	
	public Student() {}
	
	public Student(String name, int age, double weight) {
		this.name = name;
		this.age = age;
		this.weight = weight;
	}
	
	public Student(String name, int age, double weight, String gender) {
		// 调用其他的构造器完成部分属性的赋值--必须放在第一行--只能调用一句
		this(name, age, weight);
		this.gender = gender;
	}

	// 方法
	public void show() {
		System.out.println("Student [name=" + name + ", age=" 
				+ age + ", weight=" + weight + ", gender=" + gender +"]");
	}
	
	public void sayHi() {
		// this.show();
		show();
	}
	
}
